L LexiFlow 词典翻译 本地多词典优先，多个 OpenAI-compatible API 流式翻译。 选词行为 本地词典没有命中单词时不会自动消耗 API；可修改词形后重查，或手动使用大模型。 本地词典 每部 MDX 独立配置、命名和启停，MDD 资源自动关联。 ＋ 添加词典 添加外部词典 打开目录 插件词典目录 “＋ 添加词典”会将所选文件复制到 Zotero 数据目录；“添加外部词典”只保存原路径。不会把大型词典写入 zotero.sqlite。 大模型 API 可配置多个服务，并在每次翻译前从选词卡片中选择。 ＋ 添加 API 支持提示词变量：${sourceText}、 ${targetLanguage}。API Key 仅保存在本机 Zotero 首选项中。
